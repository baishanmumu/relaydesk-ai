# RelayDesk conversation service

This package contains the LangGraph workflow, specialist assistants, business tools, guardrail checks, and command-line entry point. See the [project README](../README.md) for setup and integration configuration.

Run the CLI from the repository root with `poetry run python -m relaydesk.app.main`. Travel tools need a compatible SQLite database and a valid `DEMO_PASSENGER_ID`; those values are not bundled.
