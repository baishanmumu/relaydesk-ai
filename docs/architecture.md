# 架构

## 请求路径

1. FastAPI 网页或命令行入口接收请求并恢复当前会话。
2. LangGraph 先载入可用的旅客上下文，再运行安全与业务范围检查。
3. 主助手选择旅行、电商、FAQ、表单或博客专员。
4. 专员按需调用 SQLite、Qdrant 或外部业务 API。
5. 被标记为敏感的旅行操作在工具执行前暂停，等待用户确认。
6. 主助手将工具结果整理为统一回复。

## 服务边界

- `relaydesk/` 保存 LangGraph 状态图、专员、业务工具和命令行入口。
- `web_app/` 保存 FastAPI 路由、浏览器会话数据和网页模板。
- `vectorizer/` 解析 FAQ 与业务数据并写入 Qdrant。
- `faq_extension/` 负责发现、解析和更新知识库文件。

## 本地状态

图检查点使用进程内 `MemorySaver`；浏览器聊天记录保存在 `web_app/user_data/` 的会话 JSON 中。两者都适合单机演示，不适合作为多实例生产存储。会话 JSON 和本地数据库已列入 `.gitignore`。

若启用 GoHumanLoop，外部审核凭据从环境读取。源码中不应写入实际密钥；表单等会产生外部副作用的工具必须在调用前确认。
